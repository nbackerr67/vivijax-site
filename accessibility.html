Accessibility Statement

Last updated: October 2, 2026

ViviJax Media Group LLC wants everyone to be able to use this website, including people who use assistive technologies.

Our standard

We design this website with WCAG 2.1 Level AA guidance in mind and use standard HTML and accessibility practices intended to support screen readers, keyboard navigation, browser zoom, and high-contrast settings.

Ongoing effort

Accessibility is an ongoing process. We review this website as changes are made.

If you experience difficulty using any part of this website, please contact us at support@vivijax.com and tell us what you were trying to access.
